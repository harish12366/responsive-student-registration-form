# Responsive Student Registration Form

A responsive student registration form built using **HTML, CSS, and JavaScript**.

The project allows users to enter student details, validates the submitted information, and dynamically adds the submitted data to a table without refreshing the page.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Student registration form
- Required field validation
- Custom inline validation messages
- Email format validation
- 6-digit pincode validation
- Gender selection using radio buttons
- State and country selection using dropdowns
- Dynamic table row creation using JavaScript
- Form reset after successful submission
- Prevents page refresh on form submission
- Clean and modern UI
- Horizontal scrolling table on smaller screens

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Flexbox
- CSS Media Queries
- DOM Manipulation
- Git & GitHub

## 📋 Form Fields

The form collects:

- First Name
- Last Name
- Email
- Address
- Pincode
- Gender
- State
- Country

## ⚙️ How It Works

1. Enter the required student details.
2. Click the **Submit** button.
3. JavaScript validates the entered data.
4. If the data is invalid, error messages are displayed below the relevant fields.
5. If the data is valid, a new row is dynamically created in the table.
6. The submitted data is added to the table.
7. The form is reset for the next entry.

## 📱 Responsive Design

The application is designed to work across:

- Desktop
- Tablet
- Mobile

On smaller screens, the form fields adjust to the available width and the table can be horizontally scrolled.
